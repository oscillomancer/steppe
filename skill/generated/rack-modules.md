# Rack modules

Generated by `<slug>-engine modules --markdown`; do not edit. Every built-in module type: the host modules, then the stock ones by key. `module.add` takes the key (`"vca"`) or the id; a cable end is `mo_N.<port>` or `mo_N.<knob>`. Knobs are in their units: a choice by its key, a switch as true or false. `module.describe` gives the same for any type, the library's too.

## in: In

`com.suppleaudio.rack.in` (host)

Audio from the DAW: the tracks that send to it.

- Out:
  - `l` audio: The sends' left side.
  - `r` audio: The sends' right side.
- Knobs:
  - `level` -60.0..12.0 dB = 0.0: The level of what the sends bring.

## notes: Notes

`com.suppleaudio.rack.notes` (host)

MIDI to poly pitch, gate, velocity and pressure: the home track's notes, or another track's.

- Out:
  - `pitch` pitch: Each voice's key, 1 per octave, 0 at C4, with the bend.
  - `gate` gate: 1 while each voice's key is held (or the pedal holds it); drops for a frame when a voice is retaken.
  - `velocity` unipolar: Each voice's velocity, 0 to 1.
  - `pressure` unipolar: Each voice's pressure: poly aftertouch, or channel pressure.
  - `retrigger` gate: A trigger as each note starts.
  - `bend` cv: The pitch bend, -1 to 1.
  - `modwheel` unipolar: The mod wheel (CC 1), 0 to 1.
- Knobs:
  - `voices` 1.0..16.0 = 8: How many notes sound at once: the poly outputs' channels.
  - `mode` rotate|reuse|reset|mono_last|mono_low|mono_high = rotate: How notes take channels: the next free in turn, the one that last played the key, the lowest free, or one channel for the latest, lowest or highest key held.
  - `bend_range` 0.0..24.0 st = 2.0: How far the pitch bend moves the pitch outputs.

## out: Out

`com.suppleaudio.rack.out` (host)

- In:

  - `r` audio: Right.
- Knobs:
  - `level` -60.0..12.0 dB = 0.0: The level the channel receives.

## plugin: Plugin

`com.suppleaudio.rack.plugin` (host)

A plug-in in the patch: audio through it, notes from pitch and gate cables.

- In:
  - `in_l` audio: The plug-in's left input.
  - `in_r` audio: Its right input; the left one while nothing is connected.
  - `pitch` pitch: Each voice's note, in octaves from C4: a gate's rise plays it.
  - `gate` gate: A note per voice while high.
  - `velocity` unipolar (unpatched 0.8): Each voice's velocity at its gate's rise, 0 to 1.
- Out:
  - `out_l` audio: The plug-in's left output.
  - `out_r` audio: Its right output.

## transport: Transport

`com.suppleaudio.rack.transport` (host)

The DAW's timeline as gates, clocks and phases: a patch in time with the song.

- Out:
  - `playing` gate: 1 while the transport plays.
  - `reset` gate: A trigger when playback starts or jumps: restart sequences with it.
  - `bar` gate: A trigger at each bar.
  - `beat` gate: A trigger at each beat of the meter.
  - `clock` gate: A trigger at each division, swung.
  - `bar_phase` phase: 0 to 1 through each bar.
  - `beat_phase` phase: 0 to 1 through each beat.
  - `tempo` cv: The tempo: BPM / 300.
- Knobs:
  - `division` whole|half|quarter|eighth|sixteenth|thirty_second|sixty_fourth|dotted_half|dotted_quarter|dotted_eighth|dotted_sixteenth|half_triplet|quarter_triplet|eighth_triplet|sixteenth_triplet = sixteenth: How often the clock output fires.
  - `swing` 0.0..75.0 % = 0.0: How late every second clock comes, as a share of a step.

## adsr: ADSR

`com.suppleaudio.rack.adsr`

An envelope with curved stages: gated, triggered or looping, poly.

- In:
  - `gate` gate: High starts the attack (rises at 0.5, falls below 0.25); low starts the release.
  - `retrigger` gate: A rising edge restarts the attack from the present level (while the gate is high, when gated).
  - `velocity` unipolar (unpatched 1.0): The top of each shape, 0 to 1, taken as it starts; 1 with nothing connected.
- Out:
  - `envelope` unipolar: The envelope, 0 to its top.
  - `inverted` unipolar: 1 minus the envelope: it closes as the envelope opens.
  - `end_of_cycle` gate: A 1 ms trigger as each shape reaches 0 (each cycle, when looping).
- Knobs:
  - `attack` 0.5..20000.0 ms = 5.0: How long it takes to rise from 0 to the top.
  - `decay` 1.0..20000.0 ms = 300.0: How long it takes to fall from the top to the sustain level.
  - `sustain` 0.0..100.0 % = 60.0: The level held while the gate is high, as a share of the top.
  - `release` 1.0..20000.0 ms = 400.0: How long it takes to fall to 0 once the gate is low.
  - `attack_curve` -100.0..100.0 % = 20.0: Positive rises fast and eases into the top, as an analog envelope; negative starts slowly and arrives suddenly; 0 is a straight line.
  - `decay_curve` -100.0..100.0 % = 60.0: Positive drops fast and settles into the sustain (natural for plucks); negative holds near the top, then falls.
  - `release_curve` -100.0..100.0 % = 60.0: Positive fades fast then lingers, as a sound dies away; negative holds, then cuts off.
  - `mode` gated|triggered|looping = gated: Gated holds the sustain while the gate is high; triggered plays the whole shape from any pulse; looping repeats it while the gate is high, or always with nothing in the gate.
- Presets: Pluck, Pad, Organ, Swell, Drum Hit, Breathing Loop

## arp: Arp

`com.suppleaudio.rack.arp`

An arpeggiator over held poly notes: six orders, octaves, latch.

- In:
  - `pitch` pitch: The held notes' pitches, poly (Notes' or Chord's).
  - `gate` gate: The held notes' gates, poly: a note plays while high.
  - `clock` gate: Each rising edge plays the next note; with nothing here, the song's sixteenths.
  - `reset` gate: A rising edge starts the pattern from its first note.
- Out:
  - `out` pitch: The note playing, in octaves from C4.
  - `out_gate` gate: High for each note's gate length.
- Knobs:
  - `mode` up|down|up_down|as_played|random|converge = up: The order: rising, falling, rising then falling, as the keys went down, at random, or lowest and highest closing in.
  - `octaves` 1.0..4.0 = 1: How many octaves the pattern climbs before it starts again.
  - `gate_length` 5.0..100.0 % = 50.0: Each note's gate as a share of the time between clocks; 100 % ties them.
  - `latch` true|false = false: Keep playing the notes after their keys are up, until a new chord starts.
- Presets: Up, Up-Down Two Octaves, Random Latch, Converge Legato

## bounce: Bounce

`com.suppleaudio.rack.bounce`

A bouncing ball: hits that come quicker and softer until it settles.

- In:
  - `drop` gate: A rising edge drops the ball from the top; poly.
  - `reset` gate: A rising edge drops it again with the same roughness.
- Out:
  - `hit` gate: A trigger at each impact.
  - `end` gate: A trigger as the ball settles.
  - `height` unipolar: The ball's height, 1 at the top of the drop.
  - `strength` unipolar: How hard the last hit was, held to the next: 1 for the first, then softer.
  - `air` gate: High while the ball is in the air.
- Knobs:
  - `fall` 20.0..4000.0 ms = 500.0: How long the first fall takes, to the first hit.
  - `bounce` 0.0..99.0 % = 75.0: How much of its speed the ball keeps at each hit: high bounces long, low settles soon.
  - `rough` 0.0..100.0 % = 0.0: How uneven the floor is: each bounce keeps a little more or less.
  - `loop` true|false = true: Drop the ball again as it settles, and at the start.
- Presets: Ping Pong, Dead Drop, Rubber Ball, Gravel, One Shot

## canon: Canon

  - `pitch_2` pitch: Its follower's note, held from step to step.
  - `pitch_3` pitch: Its follower's note, held from step to step.
  - `gate_1` gate: Its follower's gate, as long as the lead's was.
  - `gate_2` gate: Its follower's gate, as long as the lead's was.
  - `gate_3` gate: Its follower's gate, as long as the lead's was.
  - `all` pitch: The lead and its followers, a channel each: for a poly voice.
  - `all_gates` gate: The lead's gate and the followers', a channel each.
- Knobs:
  - `voices` 1.0..3.0 = 3: How many followers play.

## cellular: Cellular

`com.suppleaudio.rack.cellular`

A 1-D cellular automaton: rows of cells grown by a rule, as gates and CV.

- In:
  - `clock` gate: Each rising edge grows the next row; with nothing here, the song's sixteenths.
  - `reset` gate: A rising edge starts the same rows over.
- Out:
  - `cells` gate: A gate a cell, one channel each, high with the clock.
  - `tap_1` gate: One cell's gate, high with the clock: four cells spread evenly across the row.
  - `tap_2` gate: One cell's gate, high with the clock: four cells spread evenly across the row.
  - `tap_3` gate: One cell's gate, high with the clock: four cells spread evenly across the row.
  - `tap_4` gate: One cell's gate, high with the clock: four cells spread evenly across the row.
  - `value` unipolar: The row as a number from 0 to 1, the first cell the heaviest: into a quantizer.
  - `alive` unipolar: The share of the row's cells alive, 0 to 1.
- Knobs:
  - `rule` 0.0..255.0 = 90: Which of the eight neighbourhoods give a live cell, as 8 bits: 90, 30, 110, 184 are good places to start.
  - `width` 3.0..16.0 = 8: How many cells the row has; a change starts the rows over.
  - `start` middle|random = middle: One cell in the middle, or cells at random by Density.
  - `density` 0.0..100.0 % = 50.0: How many cells a random start sows.
  - `mutate` 0.0..100.0 % = 0.0: How likely a step is to flip one random cell.
  - `wrap` true|false = true: Join the row's ends, so the edges are neighbours.
  - `revive` true|false = true: Start over when the row dies out or stops changing.
- Presets: Triangles, Chaos, Crawlers, Traffic, Settling Drums

## chance: Chance

`com.suppleaudio.rack.chance`

A coin toss per gate: to A or B, latched, or as a burst of ratchets.

- In:
  - `gate` gate: The gates to toss (rises at 0.5, falls below 0.25); poly.
  - `reset` gate: A rising edge starts the same tosses over.
- Out:
  - `a` gate: The gates that came up A.
  - `b` gate: The gates that came up B.
- Knobs:
  - `chance` 0.0..100.0 % = 50.0: How likely each gate is to go to A, not B.
  - `latch` true|false = false: Hold A or B high from one toss to the next, instead of passing each gate.
  - `ratchet_chance` 0.0..100.0 % = 0.0: How likely a gate is to become a burst of pulses.
  - `ratchets` 2.0..8.0 = 3: How many pulses a burst has, spread over the time to the next gate.
- Presets: Coin, Mostly A, Random Switch, Drum Rolls

## changes: Changes

`com.suppleaudio.rack.changes`

A chord progression that writes itself in a key, voiced smoothly.

- In:
  - `clock` gate: Each rising edge moves to the next chord; with nothing here, the song.
  - `reset` gate: A rising edge starts the same progression over from the home chord.
- Out:
  - `chord` pitch: The chord's notes, lowest first, a channel each.
  - `gate` gate: High on every note of the chord, low for 2 ms as the next begins.
  - `root` pitch: The chord's root, an octave below: for a bass.
  - `degree` unipolar: Which chord of the key it is: 0 the first, 1 the seventh.
  - `next` gate: A trigger as each chord begins.
- Knobs:
  - `key` c|c_sharp|d|d_sharp|e|f|f_sharp|g|g_sharp|a|a_sharp|b = c: The key's first note: the home chord's root.
  - `mode` major|minor|dorian|phrygian|lydian|mixolydian|harmonic_minor = major: The scale the chords are built from, and so each chord's quality.
  - `length` beats_2|bar_1|bars_2|bars_4 = bar_1: How long each chord lasts while following the song.
  - `loop` 1.0..16.0 = 4: How many chords before the progression comes round.
  - `change` 0.0..100.0 % = 25.0: How likely each chord (but the first) is drawn anew as it comes round: 0 % locks it.
  - `home` 0.0..100.0 % = 40.0: How strongly the progression is drawn back to the home chord.
  - `notes` 3.0..5.0 = 3: How many notes a chord stacks: 3 triads, 4 sevenths, 5 ninths.
  - `octave` -2.0..2.0 = 0: Where the chords sit: 0 around C4.

- Presets: Four Chords, Minor Loop, Jazz Sevenths, Modal Drift, Slow Pads

## compressor: Compressor

`com.suppleaudio.rack.compressor`

A compressor: threshold, ratio, knee, attack, release, makeup; a sidechain to duck by, linked or per channel.

- In:
  - `in` audio: What to compress. Poly: each channel, linked or alone.
  - `sidechain` audio: What it listens to instead of In: a kick to duck by. A mono cable keys every channel.
- Out:
  - `out` audio: The compressed sound.
  - `gain` unipolar: The gain it applies, 1 at rest: into a VCA, it ducks something else alike.
- Knobs:
  - `threshold` -60.0..0.0 dB = -18.0: Where it starts turning down: peaks above it are reduced.
  - `ratio` 1.0..20.0 ratio = 4.0: How much: at 4, a peak 8 dB over comes out 2 dB over.
  - `knee` 0.0..24.0 dB = 6.0: How gently it eases in around Thresh: 0 is a hard corner.
